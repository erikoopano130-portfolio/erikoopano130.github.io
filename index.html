Step-by-step guide to publish your art portfolio website live in 3 minutes.

1

Create GitHub Repository

Go to GitHub.com, create a new repository (e.g. art-portfolio), set it to Public, and check "Add a README file".

2

Save File as index.html

Save this webpage file as index.html on your computer.

3

Upload index.html to Repository

In your GitHub repo page, click Add file → Upload files, drag your index.html, and click Commit changes.

4

Enable GitHub Pages

Go to Repo Settings → Pages (on left sidebar). Under Branch, select main (or master) branch and click Save.
